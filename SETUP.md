# SpeakySpeak setup — moved

Setup lives in **[INSTALL.md](INSTALL.md)** now. This file is a signpost so old links keep working.

This page used to be the install walkthrough, written 2026-07-18 for the friends beta. It went out of date: it wires only two hook events, and the app has needed four since 1.2.8. INSTALL.md is the one that is kept current, and `./install.sh` registers the hooks for you.

- **Installing:** [INSTALL.md](INSTALL.md). Paste the prompt in [README.md](README.md) and your own Claude Code will run it, or follow it yourself, one command at a time.
- **Using it:** [speakyspeak.com/howto](https://speakyspeak.com/howto) for the visual tour, [GUIDE.md](GUIDE.md) for every setting.
- **Uninstalling:** the last section of [INSTALL.md](INSTALL.md).
